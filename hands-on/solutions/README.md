Labs 8 and 9 and the end project do not have one complete model answer. They are
assessed with the [end project rubric](../../project/rubric.md), because a full
reference implementation would undermine independent design and defence.

When your answer differs, ask whether it:

- satisfies the same requirement;
- states assumptions;
- introduces understood failure modes and costs;
- includes security and operational evidence; and
- remains consistent across diagrams and decisions.
